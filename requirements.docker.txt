# Container dependency set for the OrbixAI backend.
#
# Versions are pinned to the versions proven working on the development host, so a
# rebuilt image reproduces the environment the results were measured in — a
# requirement for publishing reproducible benchmarks.
#
# Two deliberate differences from the host requirements.txt:
#
#  1. sounddevice / pyttsx3 / scipy are OMITTED. They are imported only by the
#     standalone voice/stt.py and voice/tts.py helpers and need real audio hardware
#     (PortAudio / SAPI) that a container has no access to. The served app does
#     speech-to-text with faster-whisper in-process and text-to-speech in the
#     browser, so nothing in the running system imports them.
#
#  2. langchain is OMITTED. A repo-wide search finds no `import langchain` anywhere;
#     only langgraph is actually used. It was also an active problem: langchain
#     constrains numpy<2 on Python 3.11, which conflicts with the numpy>=2 the rest
#     of the stack runs on and made the image unbuildable.
